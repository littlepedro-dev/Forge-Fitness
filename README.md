# ForgeFit — Código organizado

## Estrutura

- `index.html`: estrutura das telas, formulários, navegação e componentes.
- `style.css`: identidade visual, layout, responsividade e estilos do modal.
- `script.js`: autenticação local, armazenamento, avaliações, treinos, evolução e alimentação.

## Como executar

1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador ou pelo VS Code com a extensão Live Server.
3. O projeto carrega Chart.js e as fontes do Google Fonts pela internet.

## Observações

- Este projeto continua sendo um protótipo local: contas e dados ficam no `localStorage` do navegador.
- Não utilize senhas reais. Para autenticação segura e sincronização, será necessário integrar um backend.
- Os arquivos foram separados sem migrar a arquitetura nem alterar intencionalmente as funcionalidades.
